## 👋 你好！

欢迎来到我的个人博客！这是一个基于 Hugo + Decap CMS 构建的现代化博客系统。

## ✨ 主要特性

- **📝 后台管理** — 通过 Decap CMS 后台直接编写和发布文章
- **🎨 主题切换** — 支持亮色/暗色/自动主题切换
- **🔍 全文搜索** — 内置搜索功能，快速找到你需要的内容
- **📱 响应式设计** — 完美适配手机、平板和电脑
- **🚀 多平台部署** — 支持 Cloudflare Pages、Vercel、GitHub Pages
- **📁 Markdown 编写** — 使用 Markdown 语法，简洁高效

## 🔧 技术栈

| 组件 | 技术 |
|------|------|
| 静态站点生成 | [Hugo](https://gohugo.io/) |
| 后台管理 | [Decap CMS](https://decapcms.org/) |
| 主题 | [PaperMod](https://github.com/adityatelange/hugo-PaperMod/) |
| 部署 | GitHub Actions / Vercel / Cloudflare Pages |

## 🚀 快速开始

1. 访问 [后台管理](/admin/) 编写新文章
2. 使用 Markdown 语法编写内容
3. 保存后自动部署到线上

## 📝 如何使用后台

后台管理面板提供以下功能：

- **写文章**：支持 Markdown 编辑器，实时预览
- **管理页面**：创建和编辑独立页面（如"关于"页）
- **上传图片**：直接在后台上传和管理图片资源
- **草稿管理**：保存草稿，准备好后一键发布
